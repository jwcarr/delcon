# Delaunay consistency

A method for reducing the coregistration keypoints between two images to only those that satisfy Delaunay consistency. This package was inspired by and is a simplification of work by [Vaienti et al., 2025](https://doi.org/10.1080/15230406.2025.2566789) ([GitHub repo](https://github.com/BeatriceVaienti/georeferencing_propagation)).
